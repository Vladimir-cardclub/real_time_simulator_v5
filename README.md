
Этот адрес по умолчанию открывает файл `index.html`. Если вы хотите запустить определённую версию симулятора, добавьте к базовому URL имя нужного HTML-файла.

### Примеры:

- **Версия 3.5 (основная рабочая)**  
  [https://Vladimir-cardclub.github.io/gamefication/cardclub_partner_journey_v3_5.html](https://Vladimir-cardclub.github.io/gamefication/cardclub_partner_journey_v3_5.html)

- **Предыдущая версия 5**  
  [https://Vladimir-cardclub.github.io/gamefication/cardclub_partner_journey_v5.html](https://Vladimir-cardclub.github.io/gamefication/cardclub_partner_journey_v5.html)

- **Любая другая версия** — просто замените имя файла в ссылке, например:  
  `https://Vladimir-cardclub.github.io/gamefication/имя_файла.html`

Таким образом, не нужно для каждой версии создавать отдельный репозиторий или переименовывать файлы в `index.html`. Все версии живут в одном репозитории и доступны по прямым ссылкам.

Если вы хотите, чтобы при переходе в корень репозитория открывался список всех доступных версий, создайте `index.html` с меню-переключателем.

## Как это работает
1. Перейдите по ссылке выбранной версии.
2. Пройдите 10 экранов симулятора: выберите сегмент бизнеса, настройте кабинет, получите прогноз дохода.
3. В конце — кнопка для связи с менеджером Card.Club.

## Структура проекта
- `cardclub_partner_journey_v3_5.html` – актуальная версия симулятора с полным флоу.
- `index.html` – может использоваться как точка входа, если вы создадите файл-меню.
- Другие `.html` файлы – различные итерации страницы.

## Для разработчиков
Репозиторий предназначен для хостинга статических HTML-страниц через GitHub Pages. Просто загрузите файлы, включите GitHub Pages в настройках репозитория (ветка `main`, корень) – и все файлы станут доступны по прямым ссылкам.
